# ことばのものさし

1台の端末をまわして遊ぶ推測ゲーム。2〜6人、機内で使うために作ってある。

**遊ぶ → https://jomasato.github.io/monosashi/**

## 遊びかた

1. 両端にお題が書かれた**物差し**が出る（例: `役に立たない ↔ 役に立つ`）
2. **読み手だけ**に、物差しのどこかにある**的**が見える
3. 読み手は、そこを指すように**ことばをひとつ**声に出す。「折りたたみ傘」
4. 端末を渡す。**当て手は的が見えない状態で**、そのことばの位置まで針を動かす
5. めくって採点。交代

的の中心±4で **4点**、±9で **3点**、±16で **2点**、外れて **0点**。

**読み手には、いちばん近かった当て手と同じ点が入る。** だから読み手が手を抜く理由がない。いいことばを出すほど自分も伸びる。

1ゲームは「全員が読み手を3回ずつ」（みじかめなら2回ずつ）。2人なら6ラウンド、だいたい8分。

## パズルではない

このゲームの本体は**揉めること**。「え、折りたたみ傘そんな役に立つ側!?」から始まる会話が全部。だから同じお題が何度出ても遊べる（的の位置が毎回違う）。お題は123通り入っている。

同じ端末で遊ぶ他のゲーム（[cabin2048](https://github.com/jomasato/cabin2048)）とは違って、**全員に同じ乱数を配る仕組みには乗っていない**。勝負の構造が違うため。

## 機内で使う準備

3までやって初めて安心していい。

1. Safariで上のURLを開き、共有ボタンから**「ホーム画面に追加」**
2. 追加したアイコンから**一度起動**する
3. 搭乗前に**機内モードをONにして、もう一度アイコンから起動**できるか確認

ブラウザのタブのままだと機内で開けないことがある。得点はこの端末の中にだけ残る。

## 構成

外部依存ゼロ。CDNもWebフォントも使っていない（機内で取りに行けないため）。書体はiOSの `ui-rounded` / `ui-monospace` をそのまま使う。

| | |
|---|---|
| `index.html` | 本体。これが唯一の編集対象。お題は `SPECTRA` |
| `sw.js` | Service Worker。キャッシュ優先。**デプロイのたびに `CACHE_VERSION` を上げる** |
| `manifest.webmanifest` | ホーム画面に追加したときの見え方 |
| `tools/make_icons.py` | アイコン生成（Pillow） |
| `tools/make_artifact.py` | `index.html` からArtifact版を切り出す |

`index.html` 内の `shared:start` / `shared:end` マーカーの間が、Artifact版と共通の中身。外側はスタンドアロン用の包装なので、中身をいじるときはマーカーの内側だけを触る。

```sh
python tools/make_icons.py                 # アイコンを作り直す
python tools/make_artifact.py              # build/monosashi.html にArtifact版を出す
```

### デプロイ

`main` に push すると GitHub Pages が自動で公開する。**その前に `sw.js` の `CACHE_VERSION` を上げること。** 上げないと、すでにホーム画面に追加した端末は古い版を掴んだまま更新されない。

### お題を足す

`index.html` の `SPECTRA` に `["左のことば","右のことば"]` を足すだけ。いいお題の条件は、**連続した軸になっていること**（二択ではない）と、**答えが割れること**。「飲み物 / 食べ物」は二択なので向かない。「役に立たない / 役に立つ」は誰でも何でも置けるので向く。
